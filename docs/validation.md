# Windows 本机验证

2026-11-20：Windows 桌面环境，Microsoft Store Codex 26.1111.9664.0、WorkBuddy 5.11.3。项目命令使用 Node.js 24.17.0，浏览器集成测试另使用 Node.js 22.23.1。

| 验证 | 结果 |
| --- | --- |
| 双应用 Check | 均发现实际安装，Chrome/Node/演示视频可用 |
| 单元测试 | 4/4 通过，覆盖两种应用、关闭条件、资源路径和字节范围 |
| PowerShell/C# | Windows PowerShell 5.1 全部解析，原生辅助代码编译通过 |
| 浏览器集成 | H.264 解码、焦点隔离、Esc、自然结束、末帧停留、错误媒体、跳过、播放超时均通过 |
| 末帧与播放超时隔离 | 末帧等待超过播放看门狗期限仍有效；播放阶段循环则正确结束 |
| Codex 实际窗口 | 内部页面 8.63 秒就绪，视频完整播放 14.21 秒后交接 |
| WorkBuddy 实际窗口 | 内部页面 2.54 秒就绪，视频完整播放 14.19 秒后交接 |
| WorkBuddy 受控延迟 | 延迟接受真实就绪信号至 18.14 秒，14.20 秒视频结束后停留约 4 秒再交接 |
| 位置和大小 | 上述三个实际窗口场景，片头四边与对应应用相差不超过 2 像素 |
| 缺少 Chrome | 应用原生启动流程仍被调用并完成，无片头阻塞 |
| 片头 JS 线程卡死 | 心跳期限触发，片头关闭，应用启动流程仍完成 |
| 发布内容 | 不包含用户本机路径、连接状态、聊天数据、账户信息、原参考视频或本地配置 |

应用测试复用已经登录的现有应用，不强制退出用户工作。未通过结束本机当前聊天来模拟 Codex 完整冷启动。不同版本、未登录页面和不同语言环境仍应按 README 的实际测试命令验证。
