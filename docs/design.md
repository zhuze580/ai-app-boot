# 双应用启动动画设计

用户明确要求：GitHub 下载者既可为 Codex 本身，也可为 WorkBuddy 本身使用开场动画。

一个独立 Windows 项目，两种应用适配器，共用本地播放器。PowerShell 负责查找已安装应用、启动及验证真实窗口；JavaScript 在单独的 Chrome 窗口播放本地视频。两侧通过每次启动独立的本地状态文件交接，不开放目标应用调试端口，不读取聊天内容，不修改目标应用安装包。

应用自动查找依次考虑：用户配置路径、已运行应用、开始菜单快捷方式、卸载注册表及标准安装目录；Codex 另外支持 Microsoft Store 包。已有 DreamSkin 时优先沿用其启动方式，保留主题。启动窗口通过操作系统 UI Automation 识别可交互的内部页面，连续两次确认；无法确认时持续停留末帧，支持 Esc 跳过。窗口尺寸跟随目标应用，绝不调整目标窗口大小。

只有视频结束且应用内部页面就绪才自动关闭。跳过、媒体损坏或 Chrome 不可用时仍启动应用。运行失败显示具体原因。提供两个双击入口、配置模板、依赖检查、单元测试、真实浏览器集成测试、GitHub CI 和下载包。

根据用户后续明确要求，仓库与发行包自带原 Codex 开场裁切视频 assets/intro.mp4，默认直接播放，保留声音和原画面。素材许可与代码 MIT 许可分别说明。几何演示已移除。Windows、Node.js 22+ 和 Chrome 是运行依赖；DreamSkin 可选，不是普通下载者的前置条件。
